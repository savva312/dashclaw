# Support

Dashclaw is a community-maintained source project.

## Where to ask

- Reproducible bugs and feature requests: [GitHub Issues](https://github.com/savva312/dashclaw/issues)
- Security vulnerabilities: private reporting instructions in [SECURITY.md](SECURITY.md)
- OpenClaw installation, provider, or Gateway behavior unrelated to Dashclaw:
  the OpenClaw support channels and documentation

Include the Dashclaw commit or release, operating system, Node.js version,
OpenClaw version, relevant configuration names with values redacted, and minimal
reproduction steps.

## Supported scope

The latest v0.1.x release is supported on a best-effort basis. Linux and macOS
are tested. Windows support is experimental. Dashclaw defaults to loopback use;
public-network deployment architecture, TLS termination, identity providers,
and managed hosting are outside the support scope.

Do not post dashboard tokens, Gateway credentials, environment files, database
contents, private session output, or unredacted logs in public issues.
